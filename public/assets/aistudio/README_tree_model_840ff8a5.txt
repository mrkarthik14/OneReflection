THE LIVING TREE — INTERACTIVE 3D BOTANICAL MODEL

This is a true 3D mesh, not a flat image.

FILES
- tree_explorer.html: all-in-one offline 3D viewer, with embedded mesh data
- detailed_botanical_tree.glb: real, editable mesh for Blender and 3D applications
- tree_actual_model_preview.png: a render made from the actual .glb file

TO EXPLORE:
1. Open tree_explorer.html in a recent Chrome, Firefox, or Edge browser.
2. Drag with mouse / one finger to rotate.
3. Scroll or pinch to zoom all the way down to individual leaves.
4. Shift + drag or right-button drag to pan.
5. Click "Zoom to leaf" to jump to a single detailed leaf.
6. Click "Branches only" to hide foliage and inspect branch structures.
7. Toggle veins and leaves separately.
8. Click "Save PNG view" to capture a screenshot.

TO EDIT THE 3D MESH:
In Blender, use File > Import > glTF 2.0 (.glb/.gltf) and select detailed_botanical_tree.glb.
The GLB includes separate meshes for bark, twigs, leaves, and veins.

CONTENTS
- 2,321 individually modeled leaf blades (no flat canopy or billboard texture)
- raised central leaf vein and smaller lateral veins per leaf
- main trunk, 12 major boughs, fine twigs and petioles
- 296,836 triangles across the detailed meshes
- smoothly orbitable and zoomable geometry

Browser requirement: WebGL2 and support for DecompressionStream (modern browsers).
Note: Some leaves overlap naturally depending on viewing angle; rotating the tree or hiding other geometry will reveal them.
